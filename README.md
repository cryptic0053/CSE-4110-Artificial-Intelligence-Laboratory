## Running the code

Requirements vary per task; each directory is self-contained. In general:

```bash
git clone https://github.com/cryptic0053/CSE-4110-Artificial-Intelligence-Laboratory.git
cd CSE-4110-Artificial-Intelligence-Laboratory
```

Then open the directory for the lab you are interested in and follow the tooling
appropriate to Python.
